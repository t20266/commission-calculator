# Commission Calculator

Dark-themed commission calculator for high-ticket sales packages — trials and monthly retainers.

Single static HTML file. No build step, no dependencies.

## Local preview

Open `index.html` in any browser, or run a quick local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy

Deploys to Vercel as a static site (no framework needed).
